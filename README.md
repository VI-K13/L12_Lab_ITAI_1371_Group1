## Project Overview

This lab explores ethics, fairness, and bias in machine learning using the Adult Income dataset. We trained a Logistic Regression model to predict income categories and examined whether its predictions performed differently for males and females.

## Lab Activities

- Trained and evaluated a Logistic Regression model.
- Compared prediction accuracy between male and female groups.
- Calculated False Positive Rates (FPR) and False Negative Rates (FNR) using confusion matrices.
- Analyzed how prediction errors could affect real-world decisions, including loan approvals and hiring.
- Discussed possible approaches to reducing bias and improving model fairness.

## Tools and Technologies

Python, Google Colab, Pandas, Scikit-learn, and the UCI Adult Income Dataset.

## Project Files

The repository contains the completed Jupyter Notebook, PDF export, Reflection Journal, and Team Member Contribution Journal.

## Conclusion

This lab helped our group understand why overall model accuracy is not enough to determine whether a machine learning model is fair. Comparing results across demographic groups showed us how prediction errors can affect people differently and why fairness evaluation is an important part of machine learning development.
